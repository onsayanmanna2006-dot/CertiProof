CertiProof — one-off Preprod deployment (dev tool, not part of the public demo)

Not linked from the main app and not shipped to the GitHub Pages build (only index.html is built for production — this page only exists in npm run dev:web). Requires Lace switched to the Preprod network with a funded address. Deploys a fresh contract instance by proving and submitting entirely inside Lace — no local wallet sync, so it doesn't hit the Node OOM issue.
