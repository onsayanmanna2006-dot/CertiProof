# CertiProof Screenshots Directory

This directory contains visual verification assets for **CertiProof**.

## Screenshot Guidelines

1. **`compile-success.png`**:
   Terminal output showing `npm run compile` and generated `managed/` circuits and keys.

2. **`deployment.png`**:
   Terminal output of `npm run deploy` on Midnight Preview or Preprod.

3. **`test-success.png`**:
   Terminal output showing `npm test` passing all test cases.
